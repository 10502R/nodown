이 서비스가 해결하는 문제

폐업 사실을 늦게 안다

가맹점이 문을 닫아도 소비자에게 따로 알려주는 곳이 없어, 할부금을 내는 동안 대응 시기를 놓칩니다.

무엇을 준비할지 모른다

할부항변에는 계약서·환불 요청 기록·중단 안내문이 필요하지만, 어떤 자료가 왜 필요한지 안내가 없습니다.

자료를 정리하기 어렵다

여러 자료에 흩어진 날짜와 금액을 시간순으로 정리해 설명하는 일 자체가 부담이라 포기하게 됩니다.

전체 이용 흐름

  1. 거래 탐지 — 카드사가 장기할부·잔여 할부금이 남은 거래 중 가맹점이 폐업한 건을 찾습니다.
  2. 앱 알림 — 해당 거래의 소비자에게 카드사 앱 알림을 보냅니다.
  3. 상황 확인 — 소비자가 지금 서비스를 이용하지 못하는 상황인지 선택합니다.
  4. 자료 입력 — 계약서·문자 등을 올리면 OCR이 계약일·금액·이용기간을 읽습니다.
  5. AI 분석 — 자료를 시간순으로 정리하고 모순·부족한 증빙을 짚어 줍니다.
  6. 결과 — 규칙 엔진이 할부항변 기본요건 충족 여부와 근거를 보여 줍니다.
  7. 제출자료 — 카드사에 낼 초안을 확인·수정하고 내려받습니다.

시연 안내

  • 화면에 나오는 카드거래, 계약서, 문자는 모두 시연용 합성데이터입니다.
  • 가맹점 상태조회는 실제 국세청 API를 호출하지 않고 API 명세를 따른 합성 응답을 사용합니다.
  • OCR·AI 호출이 실패해도 화면이 멈추지 않도록 예비 데이터로 동작합니다.
  • 실제 카드사 접수나 결제취소는 수행하지 않습니다.
